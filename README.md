# Bla · Zyro Showcase

Demostraciones de Zyro por servicio, pensadas para publicarse como un solo sitio estático.
Todo el contenido está dentro de [`zyro-showcase/`](zyro-showcase/README.md); allí están la estructura, cómo probarlo y cómo publicarlo.

```
zyro-showcase/
├── plantillas/        sitio estático que se publica (seo, automatizacion)
├── fuentes/           código fuente de lo que necesita compilarse (automatizacion)
└── docs/              notas de traspaso y scripts recuperados (no se publican)
```

Antes de publicar en producción hay que subir el resto del proyecto desde el PC: ver `zyro-showcase/docs/TRASPASO.md`.
